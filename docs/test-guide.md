# Universal viewer test guide

Use a current Chrome browser. Open the supplied preview, run `npm ci` followed by `npm run dev`, or install the built Chrome package using [Chrome extension installation](chrome-extension.md). An untargeted launch starts in **Precision Engineering**, assembly **ASM-1000**, **Configuration B**, with the revision B PDF specification filling the **Documents** workspace. The Files navigator is open on wide displays and collapsed on compact displays; Details and Notes are available on demand. **Workspace settings → Local tools & handoff → Open local test files** opens a separate session for user-selected STEP, PDF, and DOCX sources.

This is an acceptance guide, not a record of completed browser checks or certification of customer files. Record actual results separately, including the build and browser used; audit and verification reports describe only their stated test runs. Fixtures, reviewers, and workspace attributes are synthetic; Preview never contacts Arena.

## Workspace navigation

| Control | Purpose | Acceptance check |
| --- | --- | --- |
| **Documents** | Read or compare PDF and Word files in the main workspace. | The document gets the available reading area. Model measurement, section, and explosion controls do not occupy this view. |
| **3D** | Inspect models and compare assembly configurations. | Model tools appear with the model; the document reader is hidden. |
| **Together** | Review a document and model in the same workspace. | Both are useful working panes. At desktop widths, drag the divider or focus it and use Left/Right arrows. At narrower widths, use the stacked panes. |
| **Files / BOM** toggle | Show or hide the navigator. | Hiding it gives space back to the content; reopening it retains access to file and BOM navigation. |
| Navigator **Files** tab | Find attachments grouped by item. | Search by filename, type, or item number; revision and edition remain visible. |
| Navigator **Bill of materials** tab | Open **Components** or **Changes**. | Component selection links to the model, and the assembly revision selector changes the resolved BOM context. |
| **Details** | Inspect the active document source or model item. | Document mode shows file identity, edition, hash, and supplied item attributes. Model mode shows the selected component or assembly context. |
| **Notes** | Read, draft, reply to, and resolve findings. | Notes open when requested. Closing the panel preserves an unposted draft. |

### Document search

Use the magnifying-glass **Find in document** control in a PDF or DOCX reader. Ctrl/Cmd+F also opens/focuses it while that reader pane has keyboard focus. In a comparison, each source has its own search. Search uses local extracted text, is case insensitive, and accepts words or phrases within a passage. Counts and highlights refer to matching passages, not each occurrence of the word. Enter and Shift+Enter move forward/backward; the buttons do the same and wrap at either end. Close, Escape and toggling Find off clear the query/highlights and return focus to Find.

| # | Workflow | Actions | Expected result |
| --- | --- | --- | --- |
| S1 | PDF across pages | Search the revision B specification PDF for `DATUM`. Use Enter, Shift+Enter, then Previous from the first result. | Five matching passages; the last result navigates to page 2 and highlights the source passage. Case differences do not prevent matching. |
| S2 | Word across pages | Search the revision B DOCX for `ASSEMBLY`, then go to the previous result from the first. Search `Inspection and review requirements`. | Five matching passages for ASSEMBLY, with the last on browser page 2; the phrase finds its page-2 heading. |
| S3 | Copied whitespace and no results | Search a known phrase with repeated spaces/newlines, then an absent string. | Whitespace normalization finds the visible phrase within its block. Fully extracted text with no match says No matching passages. |
| S4 | Keyboard and close | Focus the PDF or Word reader, press Ctrl/Cmd+F, type a query, and exercise Enter/Shift+Enter. Close via X, Escape and the Find toggle. | Shortcut affects the focused pane; it does not seize another pane or settings fields. All close paths clear highlights/query and return focus to the Find control. |
| S5 | Source and pane isolation | Search one revision pane, then the other; change the exact attachment. | Each pane retains its own search while mounted. A different source begins with an empty search. Page navigation does not replay an old search command. |
| S6 | Partial/scanned extraction | Use extraction coverage tests and suitable controlled image-only/over-limit files. | Search unavailable text is explicit; partial positive/negative results state the limitation. A scanned page is not certified as having no matching words. No OCR is performed. |

Phrases split across independent extracted blocks are not joined. Precise occurrence-level navigation, whole-word/case options, bookmarks and page thumbnails remain possible later document tools; do not present them as implemented controls.
