PLAYGROUND ASSISTANTNot connected

Connect Claude

The Playground assistant turns a typed or spoken request into proposed changes you review before applying. It calls Anthropic directly from this browser with your own Claude API key. Usage is billed to that key.

The key is stored unencrypted in this Chrome profile's extension storage and is sent only to api.anthropic.com. Anyone who can use this Chrome profile can use it. Create a separate key with a spend limit for this extension, and remove it here when you no longer need it. It is not synced and is not included in review exports or ECR packages.

Each request sends your instruction, component names, item numbers, revisions, positions and your markup notes to Anthropic. Source STEP, PDF and Word files are not sent. Check your organization's policy before using this with real product data.
